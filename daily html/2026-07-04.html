生数科技发布 Vidu S1，推动视频生成迈向"实时交互"新时代

生数科技在 2026 全球数字经济大会上发布 Vidu S1 实时交互模型，支持实时视频通话和语音控制视频走向，实现无限时长连续互动；在 540P 分辨率下实现 25FPS（最高 42FPS）实时生成，已开启内测。

AI PM 视角：Vidu S1 的发布意味着视频生成从"离线渲染"正式进入"实时交互"阶段。过去，无论是 Runway、Pika 还是 Sora，用户输入提示词后都需要等待数秒到数分钟才能获得结果，交互模式是批处理式的。而 Vidu S1 支持实时视频通话和语音控制走向，本质上把视频生成变成了一个**可对话、可中断、可迭代的交互媒介**。这对内容创作、娱乐、教育、虚拟陪伴等产品形态的影响是结构性的。 从产品竞争角度看，Vidu S1 开辟了一条与 OpenAI、Google 不同的差异化路径：不是追求最高画质或最长时长，而是追求**低延迟下的可控性和连续性**。对于 AI PM 而言，这意味着产品设计的重心需要从"如何生成更好的视频"转向"如何让视频成为用户表达和互动的自然界面"。例如，用户可以通过语音实时导演剧情发展，或者在视频通话中与虚拟角色共同创作内容。

研究型 Builder 视角：Vidu S1 采用自回归扩散路线，基于已生成画面和语音指令持续预测后续内容，并引入 TurboDiffusion 等技术降低计算成本。技术新颖性在于将视频生成建模为一个条件化的序列预测问题，而非传统的"文本→完整视频"映射。可复现性方面，目前仅开放内测，公开的技术细节有限，需要关注其官方技术报告或论文，以验证其在不同分辨率、动作复杂度和长序列下的稳定性。

可落地的方法论：- **本周可做**：梳理你产品中所有"用户需要等待 AI 生成结果"的环节，评估哪些场景可以通过流式生成或实时交互来重塑体验。 - **本季度可做**：设计一个基于实时视频生成的互动 demo，例如"语音导演短视频"或"AI 角色实时陪伴通话"，收集用户对延迟和可控性的敏感度数据。 ---

02TH

面壁智能发布 AI 全自动预训练框架 ForgeTrain，8 小时追平 Megatron-LM

面壁智能发布全球首个完全由 AI 编写、无人类干预的生产级大模型预训练框架 ForgeTrain，针对特定模型和硬件从零自动"锻造"专用训练代码；在 8 小时内追平 Megatron-LM，1.5 至 2 天内实现稳定反超，模型 FLOPS 利用率提升约 8%～10%。

AI PM 视角：ForgeTrain 标志着 AI 行业进入"AI 制造 AI"的临界点。过去，训练大模型需要大量人类工程师手动调优并行策略、内存管理、通信调度等底层细节。ForgeTrain 让 AI 自动为特定模型和硬件生成最优的训练代码，这意味着**模型训练的成本结构和人才结构都将发生根本变化**。中小企业可能不再需要庞大的 ML 系统团队，就能训练出具备竞争力的模型。 从产品战略看，这会让基础模型的竞争更加白热化。如果训练框架可以被 AI 自动优化，那么模型能力的差异化将更多取决于数据质量、算法创新和算力规模，而不是工程调优能力。对于 AI PM 来说，需要重新评估自研模型 vs 调用 API 的 trade-off：当训练成本下降时，垂直领域专有模型的商业可行性会显著提升。

研究型 Builder 视角：ForgeTrain 的核心创新是四阶段 Harness 优化流程，全程自动判定训练代码的正确性和性能。这比传统的自动调参（AutoML）更进一步，涉及到分布式训练代码的自动生成。技术可复现性方面，面壁智能声称其可迁移至不同模型（MiniCPM4-0.5B/8B）和硬件（H100 及昇腾 NPU），这是一个很强的泛化信号。研究者可以验证其在其他模型架构（如 Transformer 变体、MoE）上的表现，以及自动生成代码的可读性和可维护性。

可落地的方法论：- **本周可做**：评估你团队当前模型训练流程中，人工调优占比最高的环节，判断哪些可以被自动化框架替代。 - **本季度可做**：如果业务依赖垂直模型，设计一个 POC，比较使用现有训练框架与自动化训练框架的成本、速度和最终模型质量。 ---

阿里达摩院发布超导材料发现 AI 智能体 Elements Claw

阿里达摩院联合中国人民大学、中国科学院大学发布首个超导材料发现 AI 智能体 Elements Claw，采用"专通融合"架构，判断超导性 AUC 达 0.996，预测临界温度平均误差小于 1K；仅用 28 个 GPU 小时筛选 240 万晶体结构，预测出 6.8 万个候选材料，其中 4 种已合成并验证超导性。

AI PM 视角：Elements Claw 是"AI for Science"商业化的重要里程碑。它不仅在虚拟筛选上表现出色，更重要的是**预测出的候选材料已经经过物理合成和实验验证**，并且全部 240 万稳定晶体数据库已开放。这意味着 AI 智能体不再只是学术研究工具，而是可以作为新材料研发的基础设施，缩短从发现到验证的周期。 从产业应用看，超导材料在能源传输、磁悬浮、量子计算、医疗设备等领域有巨大价值。传统的材料发现依赖试错法，周期长、成本高。Elements Claw 将筛选效率提升数个数量级，可能让中国在关键材料领域获得先发优势。AI PM 应关注如何将这类科学发现智能体产品化：是面向材料企业提供 SaaS 筛选服务，还是作为科研机构的计算助手？

研究型 Builder 视角：该智能体的技术核心是基于 1.25 亿分子/晶体结构预训练的 1B 参数原子基础模型 Elements，以及面向超导发现的"专通融合"架构。AUC 0.996 和临界温度误差 <1K 是非常强的性能指标，但研究者需要验证其是否对训练数据存在过拟合，以及在不同材料体系（高温超导、拓扑超导等）上的泛化能力。已合成验证的 4 种材料是一个重要的 reproducibility 信号。

可落地的方法论：- **本周可做**：如果你所在行业涉及材料、化学或生物发现，研究 Elements Claw 的开放数据库，判断是否可以用于你的研发管线。 - **本季度可做**：与材料科学或相关领域专家召开一次工作坊，识别 2-3 个可以用 AI 智能体加速发现的具体目标。 ---

全球首例 AI Agent 勒索攻击曝光，从漏洞利用到数据库加密全程自主完成

安全厂商 Sysdig 首次记录到 AI Agent"JADEPUFFER"自动完成的勒索攻击，该攻击利用 CVE-2025-3248 漏洞远程执行代码，自主收集云凭证、横向移动并加密 1342 条配置数据，全程无需人工干预。

AI PM 视角：JADEPUFFER 是全球首例被公开记录的 AI Agent 自主勒索攻击，它把 AI 安全威胁从"辅助人类黑客"提升到了"独立执行完整攻击链"的级别。这对所有 AI 产品和基础设施都是一个警示：**Agent 的能力越强，被滥用后的破坏力也越大**。企业不仅需要防御传统攻击，还需要思考如何检测和遏制自主 AI Agent 的恶意行为。 从治理角度看，这一事件会加速各国对 AI Agent 安全监管的立法进程。对于 AI PM 来说，产品设计中必须内置安全护栏：限制 Agent 的权限范围、记录所有决策路径、设置人机确认机制、监控异常行为模式。同时，这也是安全产品的新机会——专门检测和对抗恶意 AI Agent 的防御系统将成为新的赛道。

研究型 Builder 视角：这次攻击展示了 LLM Agent 在漏洞利用、凭证收集、横向移动和持久化方面的组合能力。研究者需要关注的是：攻击 Agent 使用了哪些工具链和决策策略？它与人类黑客的攻击路径有何异同？更重要的是，如何构建能够检测和对抗自主攻击 Agent 的防御 Agent？这是一个攻防对抗的新前沿。

可落地的方法论：- **本周可做**：审查你产品中 AI Agent 的权限设计，遵循最小权限原则，确保 Agent 无法在没有人工确认的情况下执行高风险操作。 - **本季度可做**：建立 AI Agent 行为审计机制，记录 Agent 的所有工具调用、决策依据和异常模式，为安全响应和合规审计提供数据基础。 ---

AI PM 视角：pxpipe 提供了一种有趣的成本优化思路：当文本 token 比图像 token 更贵时，可以把密集文本"视觉化"后再输入模型。这对高上下文窗口、高工具调用频率的 Agent 产品具有直接价值。但需要注意其"有损"特性——精确 ID、路径等关键信息仍需保留为文本。

研究型 Builder 视角：这本质上是一种输入表示工程（input representation engineering），研究者可以进一步探索不同信息类型（结构化数据、代码、自然语言）的最优视觉编码方式，以及压缩率与模型理解能力之间的 trade-off。

方法论
  • 对高频调用大模型 API 的产品，评估是否可以通过输入表示优化（如图像化、结构化、摘要化）降低 30% 以上的 token 成本。
